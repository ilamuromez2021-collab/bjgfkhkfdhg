# AniWave 🌊

Адаптивный каталог аниме на русском языке. Поиск, сезонные новинки, рейтинги, жанры, карточки с описаниями и избранное.

## Запуск локально

Это статическое веб-приложение, без сборщика и установки зависимостей. Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Публикация на GitHub Pages

Репозиторий включает workflow GitHub Actions в `.github/workflows/pages.yml`. В GitHub откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации. После запуска workflow приложение будет доступно на GitHub Pages.

## Источники данных

- [Jikan API](https://docs.api.jikan.moe/) — публичный read-only API данных MyAnimeList.
- Постеры и изображения предоставляются API и принадлежат правообладателям.
- Кнопки просмотра открывают поиск по названию на Crunchyroll и YouTube; доступность зависит от региона и лицензий.

## Ограничения

Jikan имеет лимиты запросов и иногда может быть недоступен. Избранное хранится в локальном хранилище браузера. Приложение не размещает и не транслирует видео самостоятельно.

## Технологии

HTML, CSS, JavaScript, Jikan API. Нет сборки и сторонних библиотек.
